# TOOL-ANGEL Constitution

Version: 1.0.0

Status: Draft

Founder: Juan Pablo Ángel

## Mission

Create a trustworthy, modular and resilient cognitive engineering platform.

## Core Principles

1. Human sovereignty.
2. Security by design.
3. Trust before execution.
4. Architecture before code.
5. Everything is versioned.
6. Everything is traceable.
7. Everything is testable.
8. Everything is recoverable.
9. Modular by default.
10. Continuous improvement.
